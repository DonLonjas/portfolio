Cinco cosas que construí

Selección de proyectos propios. Cada uno resuelve un problema concreto que tenía.

  1. 01

    Monitor

    Dashboard web de métricas de sistema en tiempo real: CPU, RAM, discos, red y GPU. Un servidor Express recoge los datos con systeminformation y los expone mediante una API JSON que consume la interfaz.

    • Node.js
    • Express
    • systeminformation
    GitHub Demo
  2. 02

    Albion Master

    Bot de Discord para Albion Online: eventos y splits de silver, canales de voz temporales, scout de recursos con 278 mapas y mercado por IA (beta). Incluye licencias, panel de administración y 37 comandos en Español e English.

    • Discord API
    • Node.js
    Visitar
  3. 03

    Guía de desarrollo básico

    Sitio de documentación interactivo para aprender desarrollo full-stack desde cero: HTML, CSS, JavaScript, Node.js, Express, SQL, MongoDB, JSON y jQuery, con ejemplos y ejercicios.

    • HTML
    • CSS
    • JS
    • MongoDB
    • jQuery
    GitHub Demo
  4. 04

    Bot de eventos de Discord

    Bot completo de Discord para gestión de eventos, sistema de economía y distribución automática de ganancias. Soporta múltiples servidores con datos independientes y comandos en Español, English y Português. Licencia MIT.

    • Node.js
    • Discord.js
    GitHub
  5. 05

    Sameron Pizza

    Sitio web para la pizzería Sameron Pizza de Yopal: catálogo y pedidos en línea. Construido con Vite y React y desplegado en Vercel.

    • React
    • Vite
